Filter function
---------------
The filter() function is used to filter elements from a list (or any iterable) based on a condition.
It keeps only those values where the function returns True.
syntax: filter(function, iterable)

nums=[2,4,3,6,1,8,5]
#evens=[]
#for i in nums:
#    if i%2==0:
 #       evens.append(i)
#print(evens)

# we can reduce the above steps by using filter
#def check(n):
#    return n%2==0
#evens=list(filter(check,nums))
#print(evens)

# we can reduce the steps to one line using lambda function
evens=list(filter(lambda i:i%2==0,nums))
print(evens)

example:1
To list even numbers
nums=[2,9,4,1,6,3,7,5]
even=list(filter(lambda i:i%2==0,nums))
print(even)

output: [2,4,6]

example:2
To list numbers greater than 50
nums=[10,55,32,75,90,41,68]
greater=list(filter(lambda i:i>50,nums))
print(greater)
output:[55, 75, 90, 68]

Map function
------------
The map() function applies a function to every element in an iterable (list, tuple, set, etc.).

example:1

nums=[2,9,4,1,6,3,7,5]
even=list(filter(lambda i:i%2==0,nums))
print(even)
double=list(map(lambda l:l*2,even))
print(double)

output:
[2, 4, 6]
[4, 8, 12]

reduce function
---------------
reduce() is used to reduce a list of values into a single value by repeatedly applying a function.
It is part of the functools module.

example:1
nums=[2,9,4,1,6,3,7,5]
even=list(filter(lambda i:i%2==0,nums))
print(even)
double=list(map(lambda l:l*2,even))
print(double)
from functools import reduce
sum=reduce(lambda m,k:m+k,double)
print(sum)

output:
[2, 4, 6]
[4, 8, 12]
24

example:2
Program to get the cubes of numbers in list and sum of the cubes

import functools
nums=[2,3,4]
cube=list(map(lambda n:n*n*n,nums))
print("cubes of the numbers : ",cube)
sum=functools.reduce(lambda a,b:a+b,cube)
print("sum of cubes : ",sum)

inner function
---------------
An inner function (also called a nested function) is a function that is defined inside another function.
Python allows functions to be created inside other functions for better structure, 
encapsulation, and advanced concepts like closures and decorators.
 
example:1
def outer():
    print("Outer function")

    def inner(num):
        print("Inner function", num)
    return inner
    
display=outer()
display(8)

output:
Outer function
Inner function 8

example:2

def outer():
    print("Outer function")

    def inner():
        print("Inner function")
    inner()
    
outer()

output:
Outer function
Inner function

example:3
def greet():
    print("Hello everyone")
    def message():
        print("Welcome to Python Class")
    message()
greet()

output:

Decorators
-----------
A decorator in Python is a function that adds extra functionality to another function
without changing the original function’s code.
syntax:@decorator_name 

example:1
def decorator(func):
    def wraper(a,b):
      if a<b:
       a,b=b,a
       return func(a,b)
    return wraper

@decorator
def divide(a,b):
    return a/b
result=divide(5,35)
print(result)

@decorator
def sub(a,b):
    return a-b
result1=sub(5,20)
print(result1)

example:2
def decorator(func):
    def wraper(*nums):
      num=list(nums)
      if len(num)==2:
         a,b=num
         if a<b:
            a,b=b,a
         return func(a,b)
      return func(*nums)
    return wraper

@decorator
def divide(a,b):
    return a/b
result=divide(5,35)
print(result)

@decorator
def sub(a,b):
    return a-b
result1=sub(5,20)
print(result1)

@decorator
def add(*nums):
   sum=0
   for n in nums:
      sum+=n
   return sum
result2=add(4,7,3,9,6)
print (result2)

__name__
----------
__name__ is a special built-in variable in Python that tells how a Python file is being executed.
1️⃣ When a file is run directly
    python file.py
output:
__name__ == "__main__"
2️⃣ When a file is imported as a module
import file
output:
__name__ == "file"

example:
demo.py file
def add():
    return("Addition")
def sub():
    return("Subtraction")
if __name__=="__main__":
    print(add())
    print(sub())
print("demo file",__name__)

test.py file
from demo import *
#result=add()
#print(result)
print("test file",__name__)
result=add()
print(result)

output:
If we execut only demo.py file i.e python demo.py we get output as below
Addition
Subtraction
demo file __main__

If we execute test.py file i.e. test,py we get output as below
demo file demo
test file __main__
Addition

as we are using demo module in test file it is not taken as main file
