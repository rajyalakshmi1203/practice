Global vs Local variables
-------------------------
In Python, variables inside a program can be either local or global, depending on where they are created.

1. Global Variables
--------------------
A global variable is created outside any function.
It can be accessed from anywhere in the program.
If we modify a global variable inside a function, we must use the global keyword.

2. Local Variables
-------------------
A local variable is created inside a function.
It can be used only inside that function.
Local variables disappear after the function finishes.
example:
--------
name="raji"                #here name is global variable
def change():
    name2="bestha"         #here name2 is local variable
    print(name2)
change()

print(name)
#print(name2)  #here we get error to execute as it is local variable, it is not defined

count=10       #global variable defined outside the function

def update():
    global count    #to modify global variable inside the function we use global keyword
    count=20       
update()
print(count)       # here we get output as 20 because we modified global variable

factorial
-----------
The factorial of a number is the product of all positive integers from 1 to that number.
example:1
n=int(input("enter the number: "))
fact=1
for i in range(1,n+1):
  fact=fact*i
  
print("The factorial of given number is : ",fact)

example:2
def fact(n):
    result=1
    for i in range(1,n+1):
        result=result*i
    return result
res =fact(0)
print(res)

recursion in python
-------------------
A recursive function is a function that calls itself again and again until a stopping condition is reached.
example:1
def greet():
    print('HELLO')
    greet()
greet()

output: It prints HELLO 1000 times because 1000 is the default limit
we can change the limit by using sys module

example:2
import sys               
from time import sleep          #importing sleep function from time module
sys.setrecursionlimit(10000)    # changing the limit to 10000
print(sys.getrecursionlimit())
count=1
def greet():
    global count
    print('HELLO',count)
    count=count+1
    sleep(0.02)
    greet()
greet()

count=1

     print(count)

Higher order function
----------------------
A Higher-Order Function (HOF) is a function that 
1.Takes another function as an argument
2.Returns a function as a result

In simple words, a higher-order function works with functions like data.

example:
num=int(input('Enter the number : '))
def fact(num):
    if num==1:
        return 1
    return num*fact(num-1)

def square(num):
    return num*num

def cube(num):
    return num*num*num

def operation(num,operand):   # here operation() is the higher order function as it takes other function as argument
    return operand(num)

result=operation(num,cube)
print(result)

Anonymous function using lambda
-------------------------------
An anonymous function in Python is a function without a name, created using the keyword lambda.
These are also called lambda functions.
syntax:  lambda arguments : expression

example:1
cube=lambda a:a*a*a
print(cube(3))

example:2
to check number is even or odd using lambda function

check=lambda num:"Even Number" if num%2==0 else "Odd Number"
num=int(input("Enter the number : "))
print(check(num))
