A function in Python is a block of reusable code that performs a specific task.
Functions make our program modular, reusable, and clean.
example:

    print(a-b)

Modules
--------
A module is just a Python file (.py) that contains:Functions,Variables,Classes,Code
Modules help you organize your program and reuse code.
Types of Modules
1. Built-in Modules : These come with Python installation.
   Examples:
      import math
      import random
      import os
      import datetime
2.User-defined Modules: These are created by user.

How to Import a Module
--------------------------
1. Simple import
   import math
   print(math.sqrt(16))
2. Import with alias (short name)
   import math as m
   print(m.pi)
3. Import specific things
   from math import sqrt, pi
   print(sqrt(25))
   print(pi)
4. Import everything (not recommended)
   from math import *

Packages
--------
In Python, packages help you organize your code into folders (directories) so that it becomes modular, clean, and reusable.
here we are importing into another file which is outside the folder.

example:
1.created a calculator folder in this we created demo1.py,test1.py files
  calculator
    demo1.py
    test1.py
2. In demo1.py we created modules
   def add():
    print("Addition")
   def mul():
    print("multiplication")
3. In test1.py we called the modules created in demo1.py
   from demo1 import *  # here instead of * we can mention module add,mul
   add()
   mul()

the above steps are calling the modules in same folder or package

4. create a file  demo.py outside the calculator and in demo.py file we are calling the modules in calculator folder
   from calculator.demo1 import *  # here instead of * we can mention module like add,mul 
   add()
   mul()
