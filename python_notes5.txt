Break,continue in python
-------------------------
continue:
--------
The continue statement in Python is used inside loops (for or while) to skip the current iteration
 and move to the next iteration immediately.
 example:
 for v in range(10):
    if v%3==0:
        continue
    print(v)
output:
1
2
4
5
7
8

Break:
------
The break statement in Python is used to stop a loop completely.
It immediately exits the loop (for or while), regardless of the loop condition.
example:
for v in range(10):
    if v==6:
        break
    print(v)
output:
0
1
2
3
4
5

Arguments in function 
---------------------

In Python, arguments are the values you pass to a function when you call it.
They allow you to give input from outside to a function.

✅ Types of Arguments in Python

Python supports 5 types of arguments:

1️⃣ Positional Arguments
2️⃣ Keyword Arguments
3️⃣ Default Arguments
4️⃣ Variable-Length Arguments (*args)
5️⃣ Keyword Variable-Length Arguments (**kwargs)

Let’s understand each one with simple examples 👇

🔵 1. Positional Arguments

Order matters.
Values are assigned based on position.

def add(a, b):
    print(a + b)

add(10, 20)   # 10 goes to a, 20 goes to b

🔵 2. Keyword Arguments

Order does not matter.
You specify the parameter name.

def greet(name, age):
    print(name, age)

greet(age=25, name="Rajya")

🔵 3. Default Arguments

If no value is given, the default value is used.

def greet(name="Guest"):
    print("Hello", name)

greet()          # uses default
greet("Rajya")   # overrides default

🔵 4. Variable-Length Arguments → *args

Used when you don't know how many values will be passed.
Takes multiple positional arguments.

def total(*nums):
    print(sum(nums))

total(1, 2, 3, 4, 5)


nums becomes a tuple.

🔵 5. Keyword Variable-Length Arguments → **kwargs

Used when you don't know how many keyword arguments will be passed.
Takes multiple key-value pairs.

def info(**data):
    print(data)

info(name="Rajya", age=25, city="Hyd")
data becomes a dictionary.

example:
def add(a,b):
    print(a+b)
add(3,6)                              #Positional arguments

def wel(name,age):
    print("welcome", name, "age is", age)
wel(age=56,name="ravi")                        #keyword arguments

def default(name,std=4):
    print(name,"studying in std",std)
default("krishna")
default("raju",6)                           #default arguments

def add2(num1,*num2):
    sum=num1
    for n in num2:
        sum+=n
    return sum
result=add2(2,3,5,6,7)
print(result)                              #variable length arguments *args

def population(name,**klargs):
    print("name:",name)
    for k,v in klargs.items():
        print(k,":",v)
population(name="raji",age=21,loc="bangalore",country="India")  #keyword variable length arguments **kwlargs
