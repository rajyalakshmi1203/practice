Tuple
*****
1.Mutability - In List we can modify whereas in tuple we cannot modify
2.Performance - Because tuples are fixed (immutable), Python processes them faster.
3. Memory Usage - Tuples use less memory → better when storing huge fixed data.
4. syntax - In List we use square brackets [], In tuple we use parentheses ()
example
*******
demo=85,56,73,45,23
>>> type(demo)
<class 'tuple'>
>>> demo[3]
45
>>> demo[3]=56         # tuple values are immutable i.e. we cannot change
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
    demo[3]=56
    ~~~~^^^
TypeError: 'tuple' object does not support item assignment
we can store values in variables
num1,num2,num3,num4,num5=demo
>>> num1
85
If tuple values include list , the values in the list can be changed
ex:  tupA=(23,56,'king',[1,2,3,4,5])
tupA[0] , gives output 23
tupA[2] , gives the output 'king'
similarly tupA[3] , gives the output [1,2,3,4,5]
Now we can change the values in list in tuple
tupA[3][0]=9
>>> tupA
(23, 56, 'king', [9, 2, 3, 4, 5])
To check values present or not we can check
>>> 56 in tupA
True   , if it is not present it returns false

Dictionary
***********
A dictionary in Python is a collection of key–value pairs.
It is one of the most powerful and commonly used data structures.
key : value
example:1
data={'kiran': 26, 'ravi': 34, 'krishna': 40, 'raj': 25}
here kiran,ravi,krishna,raj are keys and 26,34,40,25 are values
 data['kiran']   , the output is 26
 data.get('raj') , the output is 25
 data.get('raji') , we don't get any output
 print(data.get('raji'))  , the output is None
Instead of getting the output none or anything we can display what to get the output 
data.get('raji','not found') , the output is not found

example:2
data1={'kiran':26,'ravi':34,'krishna':40,'raj':25,'kiran':59,'gopi':34}

By this we come to know that keys are to be unique and values can be any or same
